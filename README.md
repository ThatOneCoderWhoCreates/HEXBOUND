# HEXBOUND

A 3D online 1v1 arena fighting game built with Unity 6.2 and the Universal Render Pipeline (URP).

## Status

Milestone 0 (foundation): project structure, docs and packages. No gameplay yet.

## Docs

- [GDD.md](GDD.md): game design document
- [ARCHITECTURE.md](ARCHITECTURE.md): technical architecture
- [DEVELOPMENT_LOG.md](DEVELOPMENT_LOG.md): progress log
- [CLAUDE.md](CLAUDE.md): instructions for AI-assisted development

## Requirements

- Unity 6000.2.8f1
- Git with Git LFS (Large File Storage)

## Getting started

```
git lfs install
git clone https://github.com/ThatOneCoderWhoCreates/HEXBOUND.git
```

Then open the `HEXBOUND` folder in Unity Hub.
