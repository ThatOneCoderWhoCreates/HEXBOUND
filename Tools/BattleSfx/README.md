# Battle SFX

Generates the WUSHEN battle sound set (wx_*.wav, 3 variants each): weapon whooshes, dodge, jump, steel parry, clash, guard break, projectile hit, explosion, cast, magic, teleport, power-up, KO and the war drum used for round start and end.

Requirements: Python 3 with numpy and scipy. Run `python sfx.py`; files go to `out/`. Copy them to `Assets/_Project/Resources/Audio/SFX/`.
